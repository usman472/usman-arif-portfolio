# usman-arif-portfolio

Personal portfolio — AI Consulting & Automation

A lightweight, dependency-free portfolio site (HTML, CSS, vanilla JS) for
**Usman Arif**, AI Consulting & Automation practitioner based in Qatar.

**Live site:** https://usman472.github.io/usman-arif-portfolio/

## Structure

```
index.html    Markup and content
style.css     All styling (design tokens at the top of the file)
script.js     Navigation, scroll reveal, scroll-spy, back-to-top
```

No build step, no framework, no dependencies. Open `index.html` directly, or
serve the folder with any static server.

## Local preview

```bash
python3 -m http.server 8899
# then visit http://127.0.0.1:8899
```

accurate. The wording presents the practice as being actively built.
